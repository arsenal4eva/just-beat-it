# just-beat-it
Rhythm game made using godot

# Features

late, early, good, great, perfect rating for each arrow depending on how well timed the press was\
Different difficulties for each level from easy, normal, hard\
Background music for the arrow chart\
Best track, tracks played, lifetime score tracking on the homepage


# How to play

Choose a level, then the difficulty of the level.\
Use your left/right/up/down arrows and click the corresponding arrow when the arrow falls.\
Try to time the click exactly when the arrow falls into the outline.\
Score is determined by how good your performance was, number of late/early/good/great/perfect arrows.
